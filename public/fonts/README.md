# 字体

## alimama-shuheiti-bold.woff2 —— 阿里妈妈数黑体 Bold

- 来源：iconfont 字体库「阿里妈妈数黑体」
  （页面 https://www.iconfont.cn/fonts/detail?cnid=a9fXc2HD9n7s ；该页描述为「中文简体字库，
  GB2312 共计 6767 个汉字 + 52 个英文大小写 + 206 个常用标点」）。取的是页面里那份预览字体文件。
- 授权：阿里妈妈数黑体是**免费商用**字体，知识产权与相关权益归**淘宝（中国）软件有限公司**。
  使用前请以官方页面的《阿里妈妈数黑体法律声明》为准；本项目只是把它作为界面字体内置。
- 用法：`src/styles.css` 的 `@font-face` 只声明这一款，`font-weight: 100 900` 覆盖整个字重区间
  （界面上的粗细由浏览器合成），`--font` 令牌把它排在第一位，系统字体只作缺字回退。
- 换字体：把新 woff2 放进这个目录，改 `@font-face` 的 `src` 与 `--font` 令牌即可。
  等宽（`--mono`，变量标记与表格数字用）保持系统等宽：等宽是功能性的，要对齐。
